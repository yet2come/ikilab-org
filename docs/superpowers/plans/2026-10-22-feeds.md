# sitemap.xml と一覧フィード（/feed.json）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** プロジェクトと事例を `/feed.json`（JSON Feed 1.1）で出し、`/sitemap.xml` を 200 で返して `/robots.txt` から参照する。既存ページの見た目は変えない。

**Architecture:** 一覧データを `src/data/catalog.ts` に一本化し、トップ 02・03 と /projects はそこから導出する。フィードとサイトマップ index は Astro の静的エンドポイントでビルド時に生成する。検査と組み立ては依存のない純粋関数（`src/lib/feed.ts`、`src/lib/sitemap.ts`）にまとめ、`node --test` で単体テストする。

**Tech Stack:** Astro 7（`output: 'static'`）、`@astrojs/sitemap` 3.7.4、Node 26 の型ストリップで TS を直接実行（`node --test`）、`xmllint`（macOS 標準）

**Spec:** `docs/superpowers/specs/2026-10-22-feeds-design.md`

## Global Constraints

- 既存ページの見た目を変えない。HTML の差分として許すのは、/projects の全カード（11件）とトップ 03 の全事例行（3件）への `id="<key>"` 属性の追加だけ
- `/feed.json`、`/sitemap.xml`、各項目の `id`（`https://ikilab.org/items/<kind>/<key>`）は今後変えない
- 依存パッケージを増やさない
- サイトの URL は `https://ikilab.org`（`astro.config.mjs` の `site`）
- `status` は `'active' | 'planned' | 'ended'`。表示ラベルは 進行中 / 計画中 / 終了。プロジェクトの `ended` は不可
- `updated` は `YYYY-MM-DD`（JST）。フィードでは `YYYY-MM-DDT00:00:00+09:00`
- `src/lib/*.ts` は Astro や `astro:*` を import しない。`src/lib` 内どうしの実行時 import は拡張子 `.ts` 付き（例 `./feed.ts`）に限る。`node --test` から直接読めるようにするため（tsconfig は `allowImportingTsExtensions: true`）
- トップ 02 は代表6件固定（`placement: 'top'` がちょうど6件）
- 作業ブランチは `feat/feeds`（分岐元 `db62fe8`）。PR #6 は含まない
- コミットメッセージは日本語、末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

1. 将来 `catalog.ts` に項目を足すときの書き忘れ（タグ空、更新日の誤記 `2026-02-30`、key 重複）: ビルドが失敗し、どの項目のどのフィールドかがエラーに出る → Task 1 のテストで担保
2. ページのある項目の `href` の末尾スラッシュの有無: フィードの `url` は常に末尾 `/` 付きで、sitemap の `<loc>` と一致する → Task 3 のテストと Task 4 の lastmod 照合で担保
3. 同じ `updated` の項目が並ぶときの順序: 毎ビルドで同じ順序になる（差分を取る取り込み側が誤検知しない）→ Task 3 のテスト
4. フィードやサイトマップ自身が `sitemap-0.xml` に載る: 載らない → Task 5 の検査
5. カードに `id` を付けたことで、トップ 02（`ExperimentsGrid`）にも属性が漏れる: 漏れない（02 には付けない）→ Task 2 の HTML 差分比較
